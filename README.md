# PafnutiHost для Android

Приложение для доступа к зарубежным сервисам, которые ограничивают вход из России: нейросетям, музыке, онлайн-кино и рабочим инструментам.

Российские сайты и банковские приложения при этом работают напрямую, как без приложения.

## Скачать

**[Последняя версия →](../../releases/latest)** — файл `PafnutiHost-*.apk`.

Android 7.0 и новее. Телефоны, планшеты, телевизоры Android TV.

## Как установить

1. Скачайте файл `.apk` со страницы версии.
2. Откройте его. Если телефон спросит — разрешите установку из этого источника (браузеру или файловому менеджеру).
3. Запустите PafnutiHost, войдите по почте или через Telegram.
4. Нажмите на солнце в центре экрана.

Новый аккаунт сразу получает бесплатные сутки, привязка Telegram — ещё 3 дня.

Дальше приложение обновляется само: оно сообщит о новой версии и проверит файл перед установкой.

## Что внутри

- одна кнопка — подключиться;
- выбор страны и честный замер скорости до каждой;
- проверка «Что видят сайты»: какой адрес, DNS и часовой пояс видны снаружи;
- передача подписки на второе устройство: QR-код, ссылка или короткий код;
- тёмная и светлая тема, виджет на рабочий стол.

## Важно

Приложение не открывает ресурсы, запрещённые в России, и не предназначено для этого. Оплата зарубежных подписок (если сервис её требует) остаётся на вашей стороне.

## Проверка файла

У каждой версии на странице указана контрольная сумма SHA-256. Сравнить: на компьютере `certutil -hashfile PafnutiHost-1.0.20.apk SHA256` (Windows) или `sha256sum` (Linux, macOS).
